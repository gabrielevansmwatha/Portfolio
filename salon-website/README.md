# Elegant Beauty Salon Website

A modern, professional salon website built with HTML, CSS, TailwindCSS, and JavaScript. Features a clean, elegant design with responsive layout and interactive elements.

## 🌟 Features

### Design & Layout
- **Modern & Professional Design**: Clean, elegant layout with pastel/neutral color palette
- **Fully Responsive**: Optimized for mobile, tablet, and desktop devices
- **Sticky Navigation**: Smooth scrolling navigation with active link highlighting
- **Beautiful Typography**: Uses Playfair Display and Poppins fonts for elegant typography

### Sections Included
1. **Header/Navigation**: Sticky navbar with logo and navigation links
2. **Hero Section**: Full-width gradient background with call-to-action buttons
3. **About Section**: Salon information with professional credentials
4. **Services Section**: Grid layout showcasing 6 main services
5. **Pricing Section**: Three-tier pricing packages with "Most Popular" highlight
6. **Gallery Section**: Responsive image gallery with hover effects
7. **Testimonials Section**: Auto-advancing testimonial slider
8. **Contact Section**: Contact form with validation and business information
9. **Footer**: Complete footer with links and social media

### Interactive Features
- **Mobile Menu**: Responsive hamburger menu for mobile devices
- **Smooth Scrolling**: Smooth navigation between sections
- **Form Validation**: Client-side form validation with error messages
- **Testimonial Slider**: Auto-advancing testimonials with manual controls
- **Gallery Lightbox**: Click to view gallery items in lightbox
- **Scroll Animations**: Elements animate in as you scroll
- **Hover Effects**: Interactive hover effects on cards and buttons
- **Back to Top Button**: Appears when scrolling down

### Technical Features
- **SEO Optimized**: Semantic HTML with proper meta tags
- **Accessibility**: ARIA labels, focus states, and keyboard navigation
- **Performance**: Optimized CSS and JavaScript
- **Cross-browser Compatible**: Works on all modern browsers

## 🚀 Getting Started

### Prerequisites
- A modern web browser
- Basic knowledge of HTML, CSS, and JavaScript (for customization)

### Installation
1. Clone or download the project files
2. Open `index.html` in your web browser
3. The website should load immediately with all features working

## 🎨 Customization

### Colors
The website uses a pink and purple gradient theme. To change colors:
- Primary colors: `pink-500`, `purple-500`
- Secondary colors: `gray-50`, `gray-100`, `gray-800`
- Update CSS variables in `style.css`

### Content
- **Salon Information**: Update contact details, address, and hours in `index.html`
- **Services**: Modify service descriptions and pricing in the respective sections
- **Images**: Replace placeholder content with actual salon images
- **Testimonials**: Add real client testimonials

### Styling
- **Fonts**: Change fonts by updating Google Fonts link in `index.html`
- **Layout**: Modify TailwindCSS classes for different layouts
- **Animations**: Adjust animation timing in `style.css`

## 📱 Responsive Design

The website is fully responsive with breakpoints:
- **Mobile**: < 768px
- **Tablet**: 768px - 1024px
- **Desktop**: > 1024px
